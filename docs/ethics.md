# Ethics Statement — Security Assessment and Hardening

**I, Peter Adeshina (2021/1/84154CF), Department of Information Technology, FUT Minna,
in undertaking the IFT 542 Practical Assignment, declare and commit that:**

1. **Authorisation.** This assessment is conducted solely within the authorised
   local laboratory environment (`localhost`) created for this assignment. No
   external, production, or third-party system is probed, accessed, or modified.
2. **Fictitious data.** All data used — students, courses, enrolments, documents
   and credentials — is synthetic and fictitious. No real personal data,
   including any FUT Minna student, staff or system data, is involved.
3. **No harm.** No attack is performed against any system I do not own or have
   not been explicitly authorised to test. All testing is contained in the Docker
   network defined in this repository.
4. **Responsible disclosure.** Any real vulnerability discovered during the
   exercise would be reported privately to the course instructor and the
   appropriate system owner, and would not be exploited or publicised.
5. **Academic integrity.** This work is my own. Code, tests and documentation are
   produced for this assignment; where techniques from public sources are used
   (OWASP ASVS, CWE-89/79/918 etc.) they are acknowledged and applied for
   defensive purposes only.
6. **Limited scope.** Deliverables contain only the information required by the
   assignment. No credentials, secrets, or attack tooling capable of harming real
   systems are published. The vulnerable starter build is clearly labelled and is
   for controlled, local demonstration only.
